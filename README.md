# Jacob Halvorson - Portfolio

Welcome to my portfolio site! You are probably looking for this: https://jacobhalvorson.me/

This repository contains the source code for my personal portfolio website. It’s a modern, fully responsive site focused on clean minimalist design, accessibility, and performance, with dark/light theme support and subtle animations.

## Tech Stack

- **React 19.1** - Latest React with modern features
- **TypeScript 5.8** - Type-safe development
- **Vite 7.1** - Fast build tool and dev server

## Features

- Responsive, mobile-first design
- Dark & light theme support
- Smooth UI animations
- Clean, minimalist aesthetic
